# 实验内容与判读

所有可运行命令统一在 [SERVER_EXPERIMENTS.md](SERVER_EXPERIMENTS.md)。当前固定单一初始化/训练任务 seed 2026，验证和开发比较 seed 100；一次比较使用完全相同的任务、异构 CPU 与轨道缓存，保存指纹。

| 实验 | 需要回答的问题 | 主要指标 |
|---|---|---|
| 当前主对比 coupled24 | 分层 GAT-PPO 是否比本地和启发式降低任务代价 | 任务代价、成功率、均值/P95、实际失败、路由拒绝、截尾 |
| GAT vs MLP | 图交互信息是否带来贡献 | 同等训练预算下的验证曲线与冻结评估 |
| full vs node_greedy | 长期节点学习是否超越同一路由/预约的当步贪心 | 代价、热点负载、队列方差、时延尾部 |
| 路由消融 | 接触前视及其路由处理是否有效 | 路由拒绝、实际断链、成功率及代价 |
| 批次预约 / 节点 mask | 同批竞争和基本约束处理是否有用 | 拒绝率、收敛过程、队列方差、代价 |
| KKT vs equal | 静态闭式共享规则是否改善执行 | 代价、时延、利用率 |
| 48→24/72/96 | 权重与训练尺度冻结后是否能跨规模运行、保持性能 | 相对留出 48 星锚点的代价变化 |
| 负载/CPU/带宽/期限/前视 | 优势在哪些合理工况成立 | 整条敏感性曲线，包含不利点 |

同一方法的策略权重不能在评估种子上再训练。当前复用验证 seed 的结果必须标注为开发比较；单 seed 不算置信区间。正式写作至少需要完成持续训练、完整对照和机制消融；现在代码接口足以开展这些实验，但不能仅凭短训练声称收敛或满足所有论文性能结论。

平均完成时延只对完成任务统计，必须同时报告成功、断链和截尾。`mean_cost_per_admitted_task_s` 包含全时域持有成本、违约和拒绝/实际失败惩罚，不能当纯平均时延。利用率按统一到达测量窗口统计，排空阶段不计入利用率分母；任务结果继续追踪至排空结束。

判断收敛应查看足够长的 validation reward / success / P95 曲线，而非仅看 PPO loss 变小。训练 seed 固定仍有策略采样差异；多次 update 的同一任务 trace 不是多个独立统计样本。若完整方法未超过 node_greedy，应如实分析训练、状态表示和负载分布，而不能删除或故意削弱对照。

系统模型的物理成本为持有时间、期限违约与实际断链成本之和；当前实现的训练及 mean_cost_per_admitted_task_s 还包含方法层远程请求拒绝惩罚。两者关系见 [METHOD.md](METHOD.md)，不得把实现成本当成纯物理完成时延。该文档划分没有修改执行器、奖励代码或已有结果。
